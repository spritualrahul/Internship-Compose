Intern Management System
📌 About the Project

This is a simple Intern Management System created using JavaScript.

This project helps to manage intern details like ID, name, department, and score.

It uses basic JavaScript concepts such as arrays, objects, functions, loops, and conditions.

🚀 Features
Show All Interns – Display the details of all interns.
Add New Intern – Add a new intern with ID, name, department, and score.
Search Intern by ID – Find an intern using their ID.
Search by Department – Find all interns belonging to a particular department.
Update Intern Score – Update the score of an existing intern.
Calculate Average Score – Calculate the average score of all interns.

▶️ How to Run the Project
Download or clone this project.
Open the project folder in VS Code.
Make sure Node.js is installed on your computer.
Open the terminal.
Run the following command:
bash
node intern.js

The output will be displayed in the terminal.

📖 JavaScript Concepts Used
Array: To store multiple intern records.
Objects: To store individual intern details.
Functions: To perform different operations.
For Loop: To search and calculate scores.
If-Else: To check conditions.
Push(): To add a new intern to the array.
Return: To return search results and calculated values.
🎯 Learning Objective

The main objective of this project is to understand basic JavaScript concepts and learn how to perform CRUD-like operations (Create, Read, and Update) using arrays and objects.
